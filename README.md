# Personal Expense Tracker

This is a simple command-line based Personal Expense Tracker built using Python. It allows users to log daily expenses, categorize them, set a monthly budget, and track spending over time. The project also includes file-saving features to help you keep a record of your expenses between sessions.

---

## Features

- Add daily expenses with date, category, amount, and description
- Categorize expenses (e.g., Food, Home, Work, Entertainment, Misc)
- Set a monthly budget
- Track total spending against the budget
- Receive alerts when budget is exceeded
- View all saved expenses
- Save and load data from a CSV file
- User-friendly menu-driven interface

---

## How to Use

1. **Run the script**:
  Personal_Expense_tracker.py
